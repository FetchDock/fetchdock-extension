# Companion Extension for [PHP Download Router](https://github.com/PBXg33k/php-download-router)

## In active development

Send all your download jobs to a (self-hosted) [PHP Download Router](https://github.com/PBXg33k/php-download-router) server.

## Targeted browser extensions (not yet published)
- Firefox
- Chrome
